A small, self-hosted infrastructure project built as a practical DevOps portfolio. The project focuses on reproducible infrastructure, configuration management, GitOps delivery, Kubernetes operations, networking, and monitoring/observability. It runs on a Fujitsu Primergy RX2530 M2, hence the name Primergy Lab.

#### What it demonstrates

* **Terraform** for infrastructure provisioning
* **Ansible** for system configuration and cluster bootstrap
* **GitOps with Argo CD** for continuous application delivery
* **Kubernetes (k3s)** for workload orchestration
* **Prometheus, Grafana, and Alertmanager** for monitoring and alerting
* **Infrastructure as code** for repeatable rebuilds and version-controlled changes
* **Resource-aware infrastructure design** for a storage- and compute-constrained single-host environment

The infrastructure source is maintained in this repository so changes can be reviewed, reproduced, and rolled back through version control.
